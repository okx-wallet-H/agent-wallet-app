# ADR 005: UI 设计哲学

## 状态
✅ 已决定

## 背景
App 以对话为主界面，用户在聊天中完成策略配置、交易确认、信号查看。UI 需要传递资金安全的信任感，同时体现 AI Agent 的智能感。

## 决策
**暗色单一主题，Agent-First 设计，消息嵌入交易卡片。**

### 核心决策

| 决策 | 内容 |
|------|------|
| 主题 | 仅暗色主题（`#09090D` 底色），不做亮色切换 |
| Agent 人格 | 紫蓝渐变（`#6C5CE7 → #4834D4`）为唯一强调色 |
| 交易确认 | 滑动确认按钮（SwipeToConfirm），防止误触 |
| Agent 思考 | 可折叠的三步推理展示 + 跳动圆点动画 |
| 消息类型 | 不只是文本 —— 策略卡片、交易确认、信号推送都是消息 |
| 字体 | Inter（正文）+ JetBrains Mono（地址/Hash）|
| 图标 | Phosphor Icons 线条风格 |

### 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#09090D` | 接近纯黑，微带蓝 |
| 卡片/气泡 | `#131318` | 比背景稍亮 |
| 输入框 | `#1A1A22` | 最深灰 |
| 强调色 | `#6C5CE7` | 紫蓝，Agent 人格 |
| 盈利 | `#00D897` | 偏青绿，不荧光 |
| 亏损 | `#FF6B6B` | 偏暖红，不刺眼 |
| 警告 | `#FFA726` | 暖橙 |
| 毛玻璃 | `rgba(255,255,255,0.04) + blur(20px)` | 卡片背景 |

## 原因
1. **暗色** — 金融/交易类产品暗色更专注，减少视觉疲劳
2. **Agent-First** — 用户在跟 AI 对话，不是操作交易终端
3. **交易卡片嵌入** — 确认、结果、信号全部在对话流中，不跳出
4. **滑动确认** — 资金操作不能轻点，需要明确的物理手势
5. **思考过程可视化** — 让用户看到 Agent 在做什么，建立信任

## 参考
- Linear — 工具产品的克制配色
- Perplexity — AI 对话的质感
- Stripe — 金融产品的信任感

## 后果

### 正面
- 独特品牌识别（不是又一个黑白灰 App）
- 资金操作安全感强
- 交互效率高（不需要跳出对话做操作）

### 负面
- 无亮色模式（不支持户外强光场景）
- 自定义组件多（SwipeToConfirm 等），开发量大

### 缓解措施
- 亮色模式延后到 V2
- 自定义组件充分测试（尤其是滑动确认的边界情况）
